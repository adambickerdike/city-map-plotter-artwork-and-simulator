# Map attribution

Map data © OpenStreetMap contributors, licensed under the Open Data Commons Open
Database License (ODbL): https://www.openstreetmap.org/copyright

This attribution must accompany every public preview, listing, package,
download, or plotted product derived from the SVG files in this directory. It is
stored externally, and the plates are rendered with
`--attribution-mode external`, so the artwork itself stays uncluttered.

**The course lines are also OpenStreetMap data.** Each one is the OSM river
centre-line cut between two named OSM features, so the ODbL applies to the red
line exactly as it applies to the streets underneath it. See `SERIES.md` and the
`race_course` block of each `.plot.json` manifest for the endpoints, the
derivation, the measured length and the organiser sources.

The races themselves are not affiliated with, endorsed by, or licensed from this
project. Event names are used descriptively to identify the course drawn.
