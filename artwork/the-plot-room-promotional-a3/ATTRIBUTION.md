These promotional artworks adapt linework from The Plot Room's existing London city edition. Their exact source SVG paths and SHA-256 hashes are recorded in the per-design JSON files. They are decorative map typography, not navigation products.

Keep “Map data © OpenStreetMap contributors” and the copyright link on the accompanying promotional page, publication caption or packaging. Credits are outside the artwork so that the artwork contains only THE PLOT ROOM.

Letter silhouettes: Noto Sans Black and Noto Serif Black, distributed under the SIL Open Font License 1.1. No font file is needed to view, print or plot the resulting vector paths.
